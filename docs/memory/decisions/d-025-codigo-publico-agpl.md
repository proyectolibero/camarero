## Decision

El código es público y se publica bajo licencia AGPL. Cualquier persona puede leerlo,
auditarlo y autohospedarlo.

## Justificacion

Preserva el código para la comunidad y permite el autohospedaje gratuito. Es coherente con
el carácter ético del proyecto y con la ausencia de lock-in.

## Alternativas

- **Código cerrado propietario:** descartado por contradecir el propósito del proyecto.
- **Licencia permisiva tipo MIT:** descartada porque permite cerrar derivados sin devolver
  mejoras a la comunidad.
- **Business Source License:** descartada por no ser software libre pleno y por generar
  desconfianza.
