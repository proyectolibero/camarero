## Decision

La plataforma guarda datos del establecimiento (nombre, razón social, RUT, contacto y
personal con su correo) y no datos de consumidor. No hay preocupación de residencia de datos
porque el comensal no deja datos.

## Justificacion

El comensal no aporta datos personales, así que el tratamiento se limita a datos de empresa,
que la Ley 21.719 ampara con base de ejecución de contrato y no de consentimiento.

## Alternativas

- **Guardar datos del comensal:** descartado por privacidad y por la promesa de anonimato.
- **Consentimiento explícito para todo:** descartado por innecesario al no tratar datos de
  consumidor.
- **Distribución multi-región por residencia:** descartada por no ser aplicable.
