## Riesgo

El alcance del producto supera la capacidad de una persona a tiempo completo. El desarrollo
se alarga, las fases se solapan y nada llega a estar usable.

## Evaluacion

- Probabilidad: media
- Impacto: medio

## Mitigacion

§8 corta explícitamente; cada fase tiene un entregable usable.
