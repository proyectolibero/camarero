## Riesgo

El personal de sala no comprende o no usa la herramienta, especialmente el KDS. La
adopción fracasa aunque el software funcione técnicamente.

## Evaluacion

- Probabilidad: media
- Impacto: alto

## Mitigacion

Onboarding presencial, KDS con 3 botones y nada más.
